# 访谈问题库 + 学习方案模板

配合 `SKILL.md` 第 1、3、4 步。

## 访谈问题库（一次问一个，按需选用）

**分诊（先定大方向）**
1. 你要学的是**一门技术/技能**，还是**一个具体项目/代码库**？具体是哪个？
2. 目的是什么？（做出某东西 / 转岗 / 面试 / 能维护某项目 / 纯兴趣）

**摸底（现有水平，对照 Dreyfus）**
3. 你现在什么水平？完全没接触 / 会一点皮毛 / 能独立做简单的 / 想从会用到精通？
4. 有没有可迁移的相关基础？（如"会 MySQL，想学 PostgreSQL"）

**定目标与约束**
5. 想达到哪个阶段就够？（够用即可 / 能独立做项目 / 想精通）
6. 有没有**硬性产出目标**？（比如"两个月内能独立开发一个 X"）
7. 每周能投入几小时？总共想用多久？
8. 偏好：更爱看文档/视频，还是直接上手做？

> 纪律：**单次只问 1 个**，拿到答复再问下一个；发现前面答复与后面矛盾要回头**修正**。信息够了就停止提问、开始排方案。

## 模板 A：学一门技术/技能

```markdown
# 学习方案：<技能> —— 目标：<到 X 阶段 / 具体产出>

## 概览
- 现有水平：<Dreyfus 阶段>  → 目标：<阶段/产出>
- 时间预算：每周 <n> 小时，约 <N> 周
- 子技能拆解（20 小时法则）：<列出 3~6 个子技能，标出优先级>
- 非目标：<本次明确不学的>

## 阶段 1：<名称>（对应 Dreyfus 新手/起步）
- 目标（Bloom）：能<动词>……
- 学习内容：<最小必要集>
- 刻意练习：<练什么 | 达标标准 | 反馈方式>
- 阶段项目：<动手产出>
- 出阶段标准：<达到才进下一阶段>
- 复习点：<间隔复习安排>

## 阶段 2 / 3 / …（逐级抬高 Bloom 层级）
（同上结构）

## 资源
<每阶段 1~2 个精选资源，别堆链接>
```

## 模板 B：学一个项目/代码库

```markdown
# 上手方案：<项目> —— 目标：<能独立改动 / 能设计新功能>

## 概览
- 现有水平 / 目标 / 时间预算
- 技术栈与前置：<需要先补的基础>

## 阶段 1：跑起来
- 目标：能本地 run 起来、跑通测试、能戳出反应
- 练习：改一处配置/文案看效果
- 出阶段标准：能稳定启动并定位入口

## 阶段 2：追一条主链路
- 目标：能端到端讲清一个典型功能的调用链（自顶向下+自底向上）
- 产出：画出该链路的模块/时序图
- 出阶段标准：能对着代码复述数据流

## 阶段 3：接一个小任务
- 目标：任务驱动地学相关模块
- 产出：完成一个小 bug / 小特性
- 出阶段标准：本地自测通过

## 阶段 4：独立小步交付
- 目标：能提交一个可 ship 的改动
- 出阶段标准：走完开发→自测→提交流程

## 阶段 5（可选）：能设计新功能
- 目标：能为新需求出方案（此时已进入软件设计类任务，超出学习范围）

> 学到的业务规则/坑，随手记录到项目的领域记忆文件（若有记忆类技能则交给它维护）。
```

## 迭代修正提示

学习者反馈时按信号调整：
- "太难/跟不上" → 降节奏、拆更小步、补前置。
- "太简单/无聊" → 跳级、加难度、直接上项目。
- "时间不够" → 砍非目标、拉长周期、只保主线。
- "方向变了" → 回到访谈，重定目标与阶段。

## 推进把关：话术与问法（配合 SKILL.md 第 6 步）

### 闸门 1 · 完成确认（话术）
- "阶段 X 的〔阅读/练习/产出〕都完成了吗？完成了的话，跟我说一下：你做了哪个练习 / 产出物放在哪 / 跑通了什么。"
- 若含糊 → "还差哪一项？卡在哪，我帮你过。" 未完成不进闸门 2。

### 闸门 2 · 理解验收（问法模板）
每轮 2~4 题，尽量覆盖不同 Bloom 层级：

| 层级 | 问法模板 |
|------|----------|
| 理解 | "用你自己的话说，X 是什么、解决了什么问题？" |
| 应用 | "遇到〔具体场景〕你会怎么用 X？给个例子。" |
| 分析 | "X 和 Y 的关键区别是什么？什么时候该选哪个？" |
| 评估 | "这个说法对不对：〔一个常见误解〕？为什么？" |
| 创造/迁移 | "把 X 用到〔一个新情境〕上，你会怎么做？" |

### 评分与推进规则
- **通过**：关键问题能用自己的话讲清 + 至少一次成功迁移/举例 → 正反馈，进下一阶段。
- **补讲**：答得含糊/片面 → 指出具体缺口，简讲一遍，**换个角度或换个例子再问**。
- **回退**：连续答不上关键问题 → 判定"没学透"，回到该阶段内容/练习，别硬推进。
- 记录：把答错暴露的薄弱点记进笔记（若有记忆/笔记类技能，交给它维护），下轮或间隔复习时重点回问。
